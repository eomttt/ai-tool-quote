# 가격 갱신

현재는 공식 요금표에서 확인한 가격을 JSON으로 보관합니다. 사용자의 화면에는 이 데이터와 확인일이 표시됩니다. 사이트를 열 때마다 공급자 페이지를 다시 수집하지 않습니다.

## 관리할 항목

도구 특징과 가격을 분리합니다. `tools.json`은 용도·기능·사용 시 살펴볼 점을 관리하고, `pricing.json`은 구독료·월 포함량·추가 구매 가격을 관리합니다.

크레딧, Fast 토큰, GPU 시간은 각 서비스의 단위를 유지합니다. 모델별 소모량이나 예상 생성 수는 수집 대상에서 제외합니다. 구독료를 포함량으로 나눈 값은 구독료 환산이라고 표시하며, 실제 추가 구매 팩 가격과 합치지 않습니다.

연간 요금은 1년 선결제액으로 저장합니다. 월 포함량은 연간 요금제에서도 한 달 기준입니다. 연간 가격이 확인되지 않으면 필드를 비워 두며 임의의 할인율을 적용하지 않습니다.

## 정기 갱신 방식

실행 주기와 수집 방식은 아직 정하지 않았습니다. 현재 등록된 가격은 공식 자료를 확인해 JSON으로 관리하며, 자동으로 실행되는 갱신 작업은 없습니다.

### 이번 수집 결과

2026-09-21에 Google Flow의 Google AI Plus·Pro 월 구독료와 월 포함 크레딧을 추가했습니다. 구독료는 Google One 공식 요금표, 포함량과 일일 무료 크레딧은 Google Flow 도움말을 확인했습니다. 각 URL은 해당 JSON의 `sources`에 기록했습니다.

Higgsfield는 공개 요금 페이지에서 금액이 노출되지 않아 추가하지 않았습니다. Luma는 현재 공식 요금표와 기존 카탈로그의 Dream Machine 구독이 같은 상품인지 확인이 더 필요해 가격을 추가하지 않았습니다.

## 검토 기준

- 월 결제와 연 결제를 구분하고 프로모션이 일반 정가로 기록되지 않았는지 확인합니다.
- 포함량의 지급 주기, 무료 지급의 일회성 여부, 추가 구매 팩의 실제 수량과 가격을 확인합니다.
- 개인·좌석당·팀 전체 가격을 구분합니다.
- 통화, 세금, 지역, 공식 출처 URL과 확인일을 기록합니다.

로그인이 필요하거나 수집이 실패하면 마지막 확인 가격을 유지합니다. 30일이 지나면 재확인 표시를 붙이지만 목록과 요금을 숨기지 않습니다. 가격이 바뀌었는지는 공식 링크로 확인할 수 있습니다.
