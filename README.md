# 툴견적

만들고 싶은 영상과 이미지에 맞는 AI 도구를 찾고 제작 비용을 비교하는 React 웹사이트입니다.

## 현재 제공하는 기능

- 서비스 38개 탐색. 영상 28개, 이미지 25개이며 두 종류를 지원하는 서비스는 중복 등록하지 않습니다.
- 한글 별칭·모델 이름·용도 검색, 제작 용도 필터, 정렬, 최대 3개 비교.
- 수량·영상 길이·해상도·생성 시도·결제 주기에 따른 예상 비용.
- 공식 정보와 가격 출처, 검토일, 요금제 조건, 비슷한 용도의 도구.
- 데스크톱·모바일 화면, 키보드 검색 단축키 `/`, 대화상자 키보드 탐색.

**현재 금액 견적은 Runway와 Pika에 한정됩니다.** 다른 서비스의 가격은 추측하지 않습니다.
두 서비스도 검증한 모델과 생성 조건만 계산합니다. 자동 가격 수집·결제·광고 송출·콘텐츠 생성은 아직 구현하지 않았습니다.

## 실행

Node.js 22.12 이상을 사용합니다.

```sh
npm ci
npm run dev
```

개발 서버: `http://127.0.0.1:5173`

```sh
npm test
npm run build
npm run preview
```

`dist/`를 정적 호스팅에 배포할 수 있습니다. 현재 외부 서비스에 배포하거나 광고 계정을 연결하지 않았습니다.

## JSON 데이터 관리

서비스 목록은 `src/domains/catalog/data/tools.json`, 가격표는 같은 폴더의 `pricing.json`에 있습니다.
JSON에 항목을 추가하면 목록과 검색에 반영됩니다. TypeScript 로더는 Zod로 필수 필드·식별자·가격·영상 길이를 검증합니다.
식별자 중복과 없는 도구를 참조한 가격 데이터도 오류로 처리합니다.

도구 정보와 가격표를 분리했기 때문에 가격을 아직 확인하지 못한 도구도 등록할 수 있습니다.
가격에 0이나 임의 값을 넣지 말고 검토가 끝난 서비스만 `pricing.json`에 추가합니다.
추가 후 `npm test`와 `npm run build`로 확인합니다.

## 가격 데이터

`src/domains/catalog/data/pricing.json`는 2026-09-21에 공식 요금표를 검토한 스냅샷입니다.
월간 구독과 연간 선결제를 구분합니다. 가격은 미국 달러 기준이며 세금·할인·추가 팩을 제외합니다.

필요 크레딧은 `완성 수량 × 결과물당 생성 시도 × 모델별 소모량`으로 계산합니다.
등록된 요금제 중 한 달의 크레딧을 충족하는 가장 저렴한 플랜을 선택합니다.
추가 팩과 무제한 모드를 포함한 최저 결제액을 보장하는 계산은 아닙니다.

영상은 Runway Gen-4.5의 720p·5초/10초와 Pika의 Wan 3.0 720p·5초를 계산합니다.
이미지 기본 해상도는 Runway Gen-4 Image 720p, Pika Nano Banana 2 1K로 서로 다릅니다.
이미지에서 해상도를 직접 고르면 그 조건이 확인된 서비스만 금액을 표시합니다.

Pika Starter는 상업용 라이선스를 포함하지 않습니다. 해당 조건을 카드와 비교 화면에 표시합니다.
무료 일회성 크레딧·이전 잔액·이월은 월 견적에서 제외합니다.
검토 후 30일이 지나면 금액 견적을 중단하고 재확인이 필요하다고 표시합니다.

- [Runway 공식 요금표](https://runway.com/pricing)
- [Runway 모델별 크레딧](https://academy.runwayml.com/models-pricing)
- [Pika 공식 요금표와 모델별 크레딧](https://pika.art/pricing)

새 가격을 반영할 때 요금과 모델 소모량을 함께 확인하고 `checkedAt`을 갱신합니다.
수집 성공만으로 검토일을 변경하지 않습니다. 자동 수집 설계는 [가격 갱신 설계](docs/pricing-updates.md)에 정리했습니다.

## 코드 구조

```text
src/
  router/                     앱 진입점
  pages/ComparePage/           검색·조건·비교 화면 조합
  domains/catalog/
    models/                   서비스·요금제·견적 타입
    data/                     서비스 목록과 검토한 가격
    utils/                    견적 계산과 테스트
    components/               카드·조건·상세·비교
  common/
    components/Modal/         키보드와 포커스를 지원하는 대화상자
    styles/                   디자인 토큰과 반응형 스타일
```

React, TypeScript, Vite, Lucide 아이콘을 사용합니다. Vitest 테스트는 플랜 경계, 재시도 비용, 연간 결제, 미확인 조건, 오래된 가격과 카탈로그 정합성을 검증합니다.
화면의 색상 표식은 자체 제작한 이니셜 표시이며 서비스의 공식 로고가 아닙니다.
