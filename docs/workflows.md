# 쇼츠·릴스 작업 흐름

사용자의 목표를 `장면 만들기 → 영상 완성하기 → 채널 준비하기 → 게시하기 → 반응 확인하기`로 연결한다. 내용 기획과 대본 작성은 서비스 범위에서 제외한다. 도구 선택과 실제 제작·게시는 사용자가 각 서비스에서 한다.

## 데이터와 추천

`src/domains/catalog/data/workflows.json`이 작업 흐름의 원본이다. 각 단계에 준비물, 결과물, 다음 단계로 넘기는 방법, 선행 단계, 추천 도구·안내를 기록한다. 도구 추천 이유는 공식 기능을 읽고 작성한 편집 판단이며 `recommendationBasis: editorial`로 구분한다.

기존 도구는 `toolId`로 연결해 가격과 상세 패널을 재사용한다. CapCut은 이 흐름의 편집 도구로 안내하며, 확인하지 않은 구독료를 새로 만들지 않는다. 출처는 `sourceIds`로 연결하고 URL·문서 이름·확인일·접근 상태를 기록한다.

질문은 BM25로 흐름을 검색한다. 쇼츠·릴스 단서 또는 영상과 게시 플랫폼이 함께 있어야 이 흐름을 제안한다. 도구 이름만 검색하거나 썸네일·상품 이미지를 찾을 때는 기존 도구 검색을 유지한다. LLM 호출이나 자유로운 문장 추론은 하지 않는다.

제작 단계의 `toolSearch`에는 검색할 매체와 도구 ID를 기록한다. 장면 제작은 영상 생성 후보 20개를 포함한다. 영상 완성은 CapCut에 VEED·Pictory·InVideo·Adobe Firefly를 더한다. `product-profiles.json`에 기록한 영상 기능으로 후보를 정하며 이미지 편집 태그만 있는 도구를 영상 편집 후보로 넣지 않는다.

단계 안에서 도구 이름·별칭과 공식 기능 설명을 검색한다. BM25는 해당 단계 후보만 대상으로 점수를 매긴다. 검색어가 비면 추천 도구를 먼저 배치하고 전체 후보를 스크롤 목록에 표시한다. 단계 전환은 검색어를 초기화하며 페이지의 원래 질문과 필터는 바꾸지 않는다.

## 사용자 선택

- 설명·참고 이미지만 있으면 영상 제작부터 시작한다.
- 클립이 있으면 장면 생성을 건너뛴다. 편집 완료를 선택하면 편집도 건너뛴다.
- YouTube와 Instagram 중 하나 이상을 선택한다. 명시한 플랫폼을 초기값으로 쓴다.
- 플랫폼별로 기존 채널을 표시한다. YouTube 채널만 있어도 Instagram 준비 안내는 남는다.
- 준비한 단계는 숨기지 않고 건너뛰기 상태로 표시한다. 다음 단계 버튼은 필요한 단계만 연결한다.

입력이 비면 흐름 예시와 기존 도구 목록을 보여준다. 영어와 한국어 모두 서버에서 해당 언어로 렌더링한다. Enter로 검색하고 Shift+Enter로 줄바꿈한다.

## 출처 확인

2026-09-21에 Runway 이미지→영상 가이드, Higgsfield 공식 소개, CapCut 음성·자막 문서, YouTube 채널·업로드·Shorts·분석·시청 지속 시간 문서를 읽었다. Meta의 Reels 소개와 프로페셔널 대시보드 공식 문서도 읽었다.

Instagram 크리에이터 계정 도움말은 공식 검색 결과에서 문서를 찾았으나 본문 접근은 로그인 화면으로 이동했다. `login-required`로 기록하고 세부 메뉴 경로를 단정하지 않는다. Reels 소개 문서는 오래된 공식 소개이므로 길이 제한이나 현재 메뉴 위치를 근거 없이 옮기지 않는다. 앱의 도구·플랫폼 안내 링크는 사용자가 최신 화면을 확인할 수 있게 제공한다.

공식 문서는 `workflows.json`의 `sources`에서 직접 확인할 수 있다. 문서 URL이 바뀌거나 기능이 변경되면 해당 출처와 이를 참조하는 안내를 함께 갱신한다.

## 검증 범위

흐름 검색의 일치·불일치, 제작 상태별 생략, 플랫폼별 안내, 기존 채널의 부분 준비 상태, 잘못된 참조와 선행 단계 순서를 테스트한다. 화면은 실제 브라우저에서 단계 전환·도구 상세·출처·플랫폼 변경·검색 해제·언어 전환을 확인한다.
