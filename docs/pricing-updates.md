# 가격 갱신

공식 요금 페이지를 크롤링한 뒤 확인한 가격만 JSON에 반영합니다. 방문자는 저장된 데이터를 읽습니다. 사이트를 열 때마다 공급자 페이지를 호출하지 않습니다.

## 수집과 반영

1. `research/pricing-sources.json`에서 도구별 공식 URL을 관리합니다.
2. `npm run crawl:pricing`으로 HTML과 본문을 수집합니다. `-- --tool higgsfield`를 붙이면 해당 도구만 수집합니다.
3. 가격이 자바스크립트로 표시되면 브라우저에서 월·연 결제 탭을 확인합니다.
4. 검토 기록을 남긴 뒤 `pricing.json`과 `pricing-audits.json`을 함께 갱신합니다.
5. 테스트·빌드와 화면에서 가격·출처를 확인합니다.

크롤러는 Python 표준 라이브러리로 실행됩니다. 동시 요청은 최대 4개이고 요청 제한 시간은 25초입니다. 응답은 8MB까지만 저장합니다.

## 남기는 근거

| 파일                                                  | 내용                                                                                   |
| ----------------------------------------------------- | -------------------------------------------------------------------------------------- |
| `research/pricing/<수집 시각>/<도구>-<URL 해시>.json` | 요청 URL, 최종 URL, 실제 수집 시각, HTTP 상태, 본문, 제목, 원본 해시, 발견한 요금 링크 |
| `research/pricing/<수집 시각>/index.json`             | 수집 결과와 본문 파일 위치                                                             |
| `.cache/pricing-sources/<SHA256>.html`                | 받은 HTML 원본. Git에는 포함하지 않음                                                  |
| `research/review-2026-09-21.json`                     | 브라우저·공식 문서에서 확인한 가격과 조건, 검토 시각                                   |
| `src/domains/catalog/data/pricing-audits.json`        | 도구별 확인 결과, 공식 URL, 수집 방법, 근거 파일 연결                                  |

수집 성공은 가격 검증 완료를 뜻하지 않습니다. HTTP 응답이 정상이어도 로그인·로딩 화면일 수 있습니다. 수집 파일은 `unreviewed` 상태로 남고 별도 검토 기록이 어떤 값을 채택했는지 설명합니다.

본문 추출기는 자바스크립트를 실행하지 않습니다. 브라우저 확인 기록은 관찰한 요금과 조건을 적은 자료이며 전체 페이지 HTML을 대신하지 않습니다. 수집한 원문은 출처 자료로만 취급합니다.

## 가격 데이터 기준

- 월 요금은 `monthlyAmount`, 연 선결제액은 `annualAmount`로 구분합니다. 연간 계약의 월별 청구액을 월 구독으로 넣지 않습니다.
- `included`는 매월 지급량이고 `annualIncluded`는 연간 지급량입니다. 연간 수량이 따로 있으면 월 지급량으로 바꿔 표시하지 않습니다.
- 수치로 표현하기 어려운 이용 한도는 `allowanceNote`로 남깁니다. 일일 Stamina·보너스와 월 크레딧을 합산하지 않습니다.
- 통화는 USD와 KRW를 지원합니다. 환율로 바꾸지 않고 가격 정렬도 통화별로 나눕니다.
- 첫 달 할인과 갱신가를 구분합니다. 정확한 연간 총액 대신 월 환산액을 12배 한 값은 비고에 계산 근거를 밝힙니다.
- 좌석당 가격과 팀 전체 가격을 비고에 표시합니다. 실제 추가 구매 팩과 반복 결제 추가 옵션을 구분합니다.

단위당 구독료는 해당 결제 주기의 요금을 포함량으로 나눈 참고값입니다. 크레딧 소모량이나 예상 생성 횟수는 계산하지 않습니다.

## 2026-09-21 확인 결과

38개 도구의 공식 사이트·요금 페이지를 확인하고 36개 도구의 요금을 등록했습니다. Hailuo는 현재 앱과 결제 정책의 가격이 다릅니다. Tensor.Art는 과거 공식 공지의 적용 연도와 현재 결제표를 확인하지 못했습니다.

미확인 플랜·프로모션·지역 차이는 [도구별 확인 기록](../research/README.md)에 남겼습니다. Luma는 현재 앱 요금이며 이전 Dream Machine 요금과 구분합니다. Higgsfield는 브라우저에서 공개 가격을 확인했습니다.

## 다시 확인하는 시점

정기 실행 작업은 만들지 않았습니다. 필요할 때 수집 명령을 실행합니다. 가격 확인 후 30일이 지나면 재확인 표시와 함께 마지막 확인 가격을 유지합니다.

후속 수집이 실패해도 공개 가격이나 확인일은 자동 변경되지 않습니다. 새 가격을 반영할 때 출처와 검토 기록도 함께 갱신해야 합니다.
